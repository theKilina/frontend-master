Что такое CSS?

CSS (Cascading Style Sheets) — это каскадные таблицы стилей. Если HTML — это скелет страницы, то CSS — её одежда и макияж. С помощью CSS мы задаём цвета, размеры, отступы, шрифты и расположение элементов.

Важно: CSS работает по принципу каскада — стили применяются сверху вниз, и более поздние могут переопределять ранние.

Способы подключения CSS

Внешний файл

Самый правильный способ. CSS хранится в отдельном файле с расширением .css

<link rel="stylesheet" href="style.css">

Подключается в <head> HTML документа

Внутренний стиль

CSS пишется внутри тега <style> в самом HTML

<style>
  body { background: #f0f0f0; }
</style>
Инлайн-стили

CSS прямо в атрибуте style тега (использовать только в крайних случаях)

<p style="color: red; font-size: 20px;">
  Текст
</p>

Селекторы CSS

Селекторы указывают, к каким элементам применять стили.

По тегу

Выбирает все элементы с указанным тегом

p {
    color: #553D67;
    font-size: 16px;
}

Применится ко всем абзацам <p>

По классу

Выбирает элементы с определённым классом (самый частый способ)

.feature-card {
    border: 1px solid #F64C72;
    border-radius: 15px;
    padding: 20px;
}

В HTML: <div class="feature-card">

По id

Выбирает элемент с уникальным идентификатором

#header {
    background: #2F2FA2;
    color: white;
}

В HTML: <header id="header">

Сложные селекторы
/* Вложенные элементы */
.features-grid .feature-card { }

/* Дочерние элементы (только прямые потомки) */
.footer > p { }

/* Элемент с двумя классами */
.btn-primary.active { }

/* Несколько элементов */
h1, h2, h3 { }

/* Псевдоклассы */
.btn-primary:hover { }
.feature-card:first-child { }
a:visited { }

Приоритет селекторов: #id (100) > .class (10) > тег (1). Чем выше приоритет, тем важнее правило.

Цвета в CSS

В этом проекте используется моя цветовая палитра:

/* HEX-формат */
color: #F64C72;
background: #99738E;

/* RGB-формат */
color: rgb(47, 47, 162);
background: rgba(85, 61, 103, 0.7); /* a - прозрачность */

/* Названия цветов (ограничено) */
color: white;
background: black;

Текст и шрифты

font-size

Размер шрифта. Можно в px, em, rem, %

font-size: 16px;
font-size: 1.2rem;
font-size: 120%;
font-weight

Жирность шрифта

font-weight: normal; /* 400 */
font-weight: bold; /* 700 */
font-weight: 300; /* тонкий */
font-weight: 900; /* очень жирный */
text-align

Выравнивание текста

text-align: left;
text-align: center;
text-align: right;
text-align: justify;
line-height

Межстрочный интервал

line-height: 1.5; /* относительно размера шрифта */
line-height: 20px;
line-height: 150%;
font-family

Шрифт (с запасными вариантами)

font-family: 'MyFont', Arial, sans-serif;
text-decoration

Оформление текста

text-decoration: none;
text-decoration: underline;
text-decoration: line-through;

Пример из моего сайта:

.hero-title {
    font-size: 40px;
    font-weight: 700;
    color: #553D67;
    text-align: center;
}

Блочная модель (Box Model)

Каждый элемент в CSS — это прямоугольник, который состоит из:

Контент

Внешний отступ (margin)

Граница (border)

Внутренний отступ (padding)

Контент

margin

Внешний отступ — расстояние от элемента до соседей

margin: 20px; /* со всех сторон */
margin: 10px 20px; /* верх/низ, право/лево */
margin-top: 10px;
margin: 0 auto; /* центрирование */
padding

Внутренний отступ — расстояние от границы до контента

padding: 20px;
padding: 10px 15px;
padding-left: 25px;
border

Граница элемента

border: 1px solid #F64C72;
border-radius: 10px; /* скругление */
border-bottom: 2px dashed #2F2FA2;
width / height

Ширина и высота

width: 300px;
height: 200px;
width: 50%; /* от родителя */
max-width: 1200px;

Совет: Используй `box-sizing: border-box;`, чтобы padding и border не увеличивали общую ширину элемента.

* {
    box-sizing: border-box;
}

Flexbox — гибкое расположение

Flexbox помогает располагать элементы в ряд или колонку и управлять их выравниванием.

display: flex;

Включает flex-контейнер

1
2
3
.container {
    display: flex;
    gap: 20px; /* расстояние между элементами */
}
justify-content

Выравнивание по главной оси (горизонтально)

justify-content: flex-start; /* слева */
justify-content: center; /* по центру */
justify-content: space-between; /* между */
justify-content: space-around; /* вокруг */
align-items

Выравнивание по поперечной оси (вертикально)

align-items: stretch; /* растянуть */
align-items: center; /* по центру */
align-items: flex-start; /* сверху */
flex-direction

Направление элементов

flex-direction: row; /* в ряд */
flex-direction: column; /* в колонку */
flex

Как элемент будет расти/сжиматься

flex: 1; /* занимает всё свободное место */
flex: 0 0 200px; /* фиксированная ширина */

Пример из моего сайта (навигация):

.headr {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

Позиционирование

position: static

Обычное положение по умолчанию

position: relative

Относительное положение. Можно смещать относительно себя

position: relative;
top: 10px;
left: 20px;
position: absolute

Абсолютное положение. Элемент выпадает из потока и позиционируется относительно ближайшего relative-родителя

position: absolute;
top: 0;
right: 0;
position: fixed

Фиксированное относительно окна браузера. Остаётся на месте при прокрутке

position: sticky

Прилипает при прокрутке (как моя шапка)

position: sticky;
top: 0;
z-index: 1000;

Из моего сайта: Шапка с классом .headr имеет position: sticky; и прилипает к верху страницы.

Анимация и трансформации

transition

Плавный переход при изменении свойств

transition: all 0.3s ease;
transition: transform 0.5s;
transition: background 0.2s linear;

Наведи на квадрат

transform

Трансформация элемента

transform: scale(1.1); /* увеличение */
transform: rotate(45deg); /* поворот */
transform: translateX(20px); /* сдвиг */
@keyframes

Сложная анимация

@keyframes bounce {
  0% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
  100% { transform: translateY(0); }
}

.element {
  animation: bounce 2s infinite;
}

Пример из моего сайта (кнопки):

.btn-primary {
    transition: transform 0.3s ease;
}

.btn-primary:hover {
    transform: scale(1.05);
}

.btn-primary:active {
    transform: scale(0.95);
}

Адаптивный дизайн

Медиа-запросы позволяют менять стили в зависимости от размера экрана:

/* Для планшетов */
@media (max-width: 768px) {
    .container {
        margin: 0 20px;
    }
}

/* Для телефонов */
@media (max-width: 480px) {
    .features-grid {
        flex-direction: column;
    }
}
