HTML — структура веб-страниц

Hyper Text Markup Language — это язык разметки, который создаёт основу любого сайта. Всё, что ты видишь на странице, начинается с HTML-тегов.

Что такое HTML?

HTML (HyperText Markup Language) — это не язык программирования, а язык разметки. Он состоит из тегов, которые говорят браузеру, как отображать контент. Каждый тег имеет своё значение и может содержать атрибуты.

Важно: HTML отвечает только за структуру и смысловое значение контента. За красоту отвечает CSS, а за интерактивность — JavaScript.

Базовая структура HTML документа

Каждый HTML документ должен иметь определённую структуру. Вот минимальный набор:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Название страницы</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>Мой сайт</h1>
        <nav>...</nav>
    </header>
    
    <main>
        <p>Привет, мир!</p>
    </main>
    
    <footer>
        <p>© 2026</p>
    </footer>
</body>
</html>
<!DOCTYPE html>

Объявляет тип документа и версию HTML (HTML5)

<html>

Корневой элемент страницы

<head>

Служебная информация: meta-теги, заголовок, подключение стилей

<body>

Видимая часть страницы

Основные теги

<h1> - <h6>

Заголовки разных уровней. h1 — самый важный, используется один раз на странице. h6 — самый маленький.

<h1>Главный заголовок</h1>
<h2>Подзаголовок</h2>
<h3>Заголовок третьего уровня</h3>
<p>

Абзац текста. Автоматически добавляет отступы сверху и снизу.

<p>Это пример абзаца с текстом. Здесь может быть много строк.</p>
<a>

Ссылка. Обязательный атрибут href указывает адрес перехода.

<a href="https://example.com">Перейти на сайт</a>
<a href="#section">Якорь внутри страницы</a>
<img>

Изображение. Одиночный тег (самозакрывающийся). Обязательные атрибуты src и alt.

<img src="images/cat.jpg" alt="Рыжий котик" width="300">
<div>

Универсальный блочный контейнер. Используется для группировки элементов.

<div class="container">
  <h2>Заголовок</h2>
  <p>Текст</p>
</div>
<span>

Строчный контейнер. Для выделения части текста.

<p>Текст со <span class="highlight">выделенным</span> словом.</p>
<br>

Перенос строки. Одиночный тег.

Первая строка<br>
Вторая строка
<strong> и <em>

strong — жирное выделение, em — курсив (логическое ударение).

<strong>Важный текст</strong>
<em>Акцентированный текст</em>

Семантические теги HTML5

Семантические теги не только создают структуру, но и объясняют браузеру и разработчикам смысл содержимого.

<header>

Шапка сайта или раздела. Обычно содержит логотип, навигацию, заголовок.

<nav>

Навигационное меню. Содержит ссылки по сайту.

<main>

Основное уникальное содержимое страницы. Должен быть один на странице.

<article>

Независимая статья или пост. Может существовать отдельно.

<section>

Смысловой раздел. Группирует связанный контент.

<aside>

Боковая панель. Содержание, связанное с основным контентом.

<footer>

Подвал сайта. Контакты, копирайт, дополнительные ссылки.

<figure> и <figcaption>

Для иллюстраций с подписями.

<article>
    <header>
        <h2>Заголовок статьи</h2>
        <p>Опубликовано: 11 марта 2026</p>
    </header>
    
    <p>Текст статьи...</p>
    
    <figure>
        <img src="image.jpg" alt="Иллюстрация">
        <figcaption>Подпись к картинке</figcaption>
    </figure>
    
    <footer>
        <p>Автор: Анна</p>
    </footer>
</article>

Атрибуты тегов

Атрибуты добавляют тегам дополнительные свойства. Пишутся в открывающем теге: <тег атрибут = "значение">

id

Уникальный идентификатор элемента

class

Класс для CSS (можно несколько через пробел)

style

Инлайн-стили (не рекомендуется)

title

Подсказка при наведении

alt

Описание изображения (для img)

src

Путь к файлу (для img, script)

href

Адрес ссылки (для a)

target

Как открывать ссылку (_blank — в новой вкладке)

Списки

<ul> и <li>

Маркированный список (ненумерованный). Каждый пункт в <li>.

<ul>
  <li>Первый пункт</li>
  <li>Второй пункт</li>
</ul>

Результат:

  • Первый пункт
  • Второй пункт
<ol> и <li>

Нумерованный список.

<ol>
  <li>Шаг первый</li>
  <li>Шаг второй</li>
</ol>

Результат:

  1. Шаг первый
  2. Шаг второй

Таблицы

Таблицы состоят из строк и ячеек:

  • <table> — контейнер таблицы
  • <tr> — строка таблицы
  • <td> — ячейка с данными
  • <th> — ячейка-заголовок (жирный текст)
  • <thead> — шапка таблицы
  • <tbody> — тело таблицы
<table>
    <thead>
        <tr>
            <th>Имя</th>
            <th>Возраст</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Анна</td>
            <td>25</td>
        </tr>
        <tr>
            <td>Иван</td>
            <td>30</td>
        </tr>
    </tbody>
</table>

Формы

Формы нужны для отправки данных на сервер:

<form>

Контейнер формы

<input>

Поле ввода (текст, пароль, email)

<textarea>

Многострочное поле

<select> и <option>

Выпадающий список

<button>

Кнопка

<label>

Подпись к полю

<form action="/submit" method="POST">
    <label for="name">Имя:</label>
    <input type="text" id="name" name="name" required>
    
    <label for="email">Email:</label>
    <input type="email" id="email" name="email">
    
    <label for="message">Сообщение:</label>
    <textarea id="message" name="message" rows="4"></textarea>
    
    <button type="submit">Отправить</button>
</form>
